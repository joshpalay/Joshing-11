Opportunities to improve

Gap · QA coverage

The OTP-verification bypass has no counterpart for the SMS reminder confirmation send. A QA test account can complete signup but can never reach the “opted-in” success state through the real UI — only by writing to the database directly.

Worth extending the same allowlist to skip sendSms for the confirmation message too, so the full happy path is exercisable end-to-end.

Design risk · crafting screen

The crafting screen is conditional on generation still being in flight. In this run it had already finished, so the screen — and the “you’re set” confirmation note built for it — never appeared at all.

The confirmation may be seen rarely in practice. Worth a lighter-weight acknowledgment (e.g. an inline toast on the reminder-ask screen itself, before navigating) as a backstop that doesn’t depend on the wait being slow.

Copy accuracy · invite links

“No category — carries all your topics” is inaccurate: it carries only the 3 curated invite_seed_interests, never the account’s full topic list once that curated set is non-empty. This actively misled the walkthrough until the resolution code was read directly.

Reword to something like “carries your 3 tagged topics” so the UI matches getInviteLinkSeedTopics’s actual behavior.
